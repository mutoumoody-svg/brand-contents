# 依赖安全修复

本轮针对主项目npm audit的8个依赖告警修复，不代表对整个网站进行了完整安全审计。

- Express 4.22.3，proxy-addr 2.0.8：修复代理IP信任子网问题。
- qs 6.16.0、body-parser 1.20.8：修复参数解析拒绝服务问题。
- Mammoth 1.13.0、xmldom 0.8.15：修复XML注入及解析资源消耗问题。
- Multer 2.4.0：替换已废弃的1.x，并验证memoryStorage、上传和大小限制错误处理。
- Mammoth的argparse限定为2.0.1，移除没有可用修复版的sprintf-js。仅override Mammoth依赖；已测试其旧命令行接口与DOCX纯文本解析。
- 锁文件固定完整依赖树，服务器必须运行npm ci才能更新依赖。

核验：npm audit 0个已知漏洞；回归测试包含登录、TXT/DOCX/PPTX上传、20MB限制、任务恢复与重试、IP信任规则和Mammoth CLI。
PDF解析实现未改变，本轮未新增PDF样本回归。

部署仍使用离线Git bundle。先上传bundle，备份，快进合并，执行npm ci、npm run check、npm test、npm audit，然后重启PM2。任何一步失败即停止。
