# Brand Center 用户手册

版本：2026-10-07 · 对应线上提交 f73000c

网站：https://brand.riverline.com.cn

适用对象：品牌内容编辑、运营人员及管理员。
本手册按现有代码和页面整理；AI、邮件、飞书及采集的真实效果取决于服务配置和网络。

## 1. 第一次使用：建议顺序

1. 用注册邮箱登录；尚未注册则申请注册，等待管理员审核。
2. 在“品牌管理”建立品牌资料，填写真实卖点、人群、禁用表达。
3. 在“小红书文案”录入写法方法，或从参考笔记提炼方法。
4. 在“内容工作台”选择品牌、填写主题，先生成3篇。
5. 逐篇核对事实，检查重复度，人工修改后保存。
6. 复制文案、制作海报，在小红书人工发布。
7. 回到任务中填写发布链接、互动数据和修改意见。

日常主流程：品牌资料 → 写作方法 → 原创任务 → 编辑与查重 → 人工发布 → 效果反馈。

## 3. 登录、注册和密码恢复

### 登录与注册

登录用户名是注册邮箱，不是页面显示的姓名。新注册用户需管理员审核后才能使用业务功能。
登录成功后通常进入“小红书文案”。公共设备使用完毕请点击“退出”。

### 忘记密码

1. 在登录页点击“忘记密码？”。
2. 填写自己在网站注册的邮箱，点击“获取验证码”。
3. 检查收件箱和垃圾邮件，填入6位验证码。
4. 填写两次新密码，点击“重置密码”。
5. 返回登录页，使用新密码登录。

新密码至少8个字符，最多72个UTF-8字节；含中文时字节数可能大于字符数。
验证码10分钟有效，重发后旧码失效，60秒内不能重复发送。
单个验证码最多尝试5次；每个邮箱每小时最多发送5次。
成功重置后，该用户以前的登录令牌失效，其他设备需重新登录；不会改变审核状态或删除内容。

系统统一发件邮箱为管理员配置的jingzhangnz@163.com，验证码寄给每位用户自己的注册邮箱。
统一提示“若邮箱已注册，将收到验证码”不代表一定投递成功，也不会向未注册邮箱发送验证码。
不要把验证码、邮箱授权码或密码发给他人。

## 4. 品牌管理：先把事实准备好

### 手工建立品牌

1. 点击“新建品牌”，填写品牌名称。
2. 补充所属行业、价格定位、Slogan、人群画像和品牌调性。
3. 添加关键词和禁忌词；标签输入后按回车。
4. 填写品牌价值观、故事、风格示例以及消费者洞察。
5. 完整保存，或先“直接保存”基础资料，后续再补充。
6. 点击“设为当前品牌”。进入不同生成页面后仍需确认品牌选择是否正确；工作台有独立品牌选择。

消费者资料建议包含：购买顾虑、购买后评价、用户自己的表达、触发购买的场景和分享理由。
未经确认的认证、功效、价格、销量或保温时长不要作为确定事实录入。

### 文件导入

编辑品牌时可上传PDF、Word（DOCX）、PPT（PPTX）或TXT，最大20MB。
系统先提取文字，再由AI辅助填入品牌字段；检查识别结果后再保存。
扫描PDF或纯图片文件可能没有可提取文字。文件只有前6000字符进入后续解析，重要资料尽量放在前面。

### 消费者评论分析

选择品牌，点击“分析评论”，按弹窗要求录入评论，生成报告后点击“保存报告”。
分析是辅助判断，不能把少量评论推断当作全体消费者结论。

## 5. 小红书方法学习

### 手工建立方法卡

填写方法标题、文案类型、适用场景、结构公式、写作逻辑、示例/注意事项和标签，点击“保存方法”。
名称应描述可复用写法，例如“通勤场景对比法”，而不是只写产品名。

示例方法：

- 名称：购买前疑问对比法。
- 场景：用户下单前犹豫。
- 结构：疑问进入 → 选择标准 → 实际细节 → 适合与不适合 → 轻建议。
- 逻辑：先帮助用户判断，再呈现品牌事实。
- 注意事项：不虚构对比数据，不冒充真实购买者。

### 从参考笔记学习

1. 进入“学习爆文”，粘贴标题和完整正文。
2. 在“写法归类命名”填写你希望保存的方法名称。
3. 点击“分析写法”，检查AI提炼结果。
4. 点击“保存为方法卡”；需要保留原文样本时再点击“保存到爆文库”。

右侧“自定义写法类型”可快速录入方法，再到方法库完善。
“学习”是保存资料并在后续提示中使用，不是训练或修改Claude模型参数。

## 6. 原创批量产出：内容工作台

### 创建任务

在“小红书文案”的“产出文案”填写参数后生成，会进入工作台查看任务。
也可以直接在工作台“创作任务”页创建。

1. 选择品牌，填写主题（必填）。
2. 选择目标，补充人群、真实卖点及禁用表达。
3. 选择3–10篇及差异化强度。
4. 勾选写作方法，点击“创建生成任务”。

未选择方法时会使用最近4个方法（如果方法库已有内容）。
未从原页面传入参考样本时，工作台任务会读取最近3条爆文样本；生成前应确保样本与业务相关。
主题、人群、卖点越具体，文案越容易贴近真实产品；缺少资料时仍需人工审稿。

| 差异化强度 | 适用情形 |
| --- | --- |
| 稳定 | 品牌语气保持一致，调整场景和切口 |
| 明显 | 日常批量内容，希望各篇角度和结构不同 |
| 探索 | 测试更丰富的叙事方式，仍保留品牌底线 |

### 任务与恢复

任务会保存到服务器。关闭浏览器不停止已经提交的任务，重新打开后可查看。
服务器重启会把未完成任务暂停；点击“继续/重试失败篇”恢复。
“暂停后续生成”在当前篇处理完成后生效，不会立即取消正在进行的AI请求。
“重试此篇”仅重新生成失败篇。重试、自动重写会增加AI调用量。
每用户最多同时保留3个等待或执行中的任务。任务按服务器单进程队列顺序执行，等待时不要重复创建。

### 逐篇编辑与保存

1. 在文案框里修改内容，检查标题、事实、语气及标签。
2. 点击“保存修改与反馈”。修改中不要直接关闭页面。
3. 点击“保存到内容库”，将文案纳入内容记录；重复点击不会重复创建同一篇记录。
4. “复制文案”复制当前文本；“导出文案”导出整批已保存内容为TXT。
5. “重新检查”会保存当前内容并重新计算历史文字重合度。

草稿自动保存与保存到内容库是两件事。导出前请保存修改。
多人或多窗口同时编辑产生版本冲突时，刷新任务后重新处理，不要强行覆盖。

## 7. 相似度检查怎么用

各主页面左下角有“相似度检查”按钮，可打开自动历史检查开关，或粘贴文案手动检查。
在工作台“相似度检查”页选择品牌、粘贴待检文案，可额外填写参考文案。

检测主要比较字符片段重合，包含同品牌内容库、已保存草稿和接入检查的近期生成结果。
未指定品牌时内容在未指定品牌的历史池比较，建议生成与查重时选中正确品牌。
工作台文字重合度达到45%会标记复核；自动生成遇到高重合时尝试重写一次，仍有问题会保留复核提示。
旧仿写入口还使用各自的本轮比较阈值，显示方式不完全相同。

这个百分比不是原创率，也不是平台给出的查重结果。低重合不保证风格不同或一定可发布。
最终还需比较：开头、场景、观点、证据顺序、句式节奏和结尾是否重复。
结构分析和部分规划请求不自动重写；需要时可手动检查最后文案。

## 8. 文案生成与优化

### 全新生成

在“文案生成”选择品牌，按需填写产品名称、价格、人群、核心卖点、品牌理念、平台和字数。
产品名称、价格、人群、卖点可以留空；至少提供品牌资料或明确写作方向，避免得到泛泛内容。
选择一种或多种思路后生成：

| 思路 | 写作重点 |
| --- | --- |
| 顾客任务 | 用户想解决什么问题 |
| 场景思维 | 产品在什么时候有价值 |
| 情绪思维 | 用户的情绪变化 |
| 活人思维 | 自然口语与具体细节 |
| 身份思维 | 用户认同的价值和身份 |

字数是生成目标，并非精确计数保证。生成后查看保存状态，复制选中的版本；历史记录可展开、复制和删除。

### 优化改写

切换“优化改写”，粘贴已有文案，填写优化目标，生成诊断及修改版本。
适合已有初稿的精修，不建议反复对同一篇换同义词代替新内容规划。
这类旧入口主要在页面内生成，不具备工作台的任务恢复能力；完成后及时保存。

## 9. 爆文仿写与文案分析

“爆文仿写”支持参考文字或截图，可使用快速仿写、深度分析后的仿写、版本继续改写及文案诊断等页面入口。
按当前页面顺序选择品牌、提供参考、填写产品和补充要求，再生成与编辑版本。
小红书链接提取依赖已配置的采集/提取服务；提取失败时直接粘贴完整标题和正文。
截图文字需清晰，识别后核对数字、产品名和事实。

原创模块适合长期批量生产；仿写模块适合研究某篇参考的传播方法。
仿写不是直接复制原文或仅替换产品名，仍需改变场景、开头、内容推进及结尾。
检查版本保存提示，在页面的历史区查看记录；编辑后确认重新保存。

独立“文案分析”页面可粘贴文字或上传截图，选择品牌后点击“开始深度分析”。
分析用于理解写作机制，不等于事实核验或发布效果预测。

## 10. 爆文库与内容记录

### 爆文库

点击“添加爆文”，填写名称、正文、平台、点赞估算和风格标签，点击“保存并分析”。
可按风格筛选、查看或重新分析样本、生成3个仿写版本及查看综合洞察。
样本应覆盖不同人群、场景和结构，避免全部来自相同作者或同一种标题套路。
点赞估算是手工参考信息，不是系统验证的实时数据。

### 内容记录

生成页面的历史记录与工作台“保存到内容库”用于保留自己的产出；海报历史保存内容规划。
当前没有独立的全功能内容库导航页，可从对应生成页面历史区和工作台任务记录查看。
共享内容查询最多返回最近300条；自己的工作台任务列表显示最近50个任务。
删除不等于归档，删除前保存需要保留的副本。

## 11. 图片海报

1. 填写海报主题，补充核心要点。
2. 按需选择品牌和配色，生成7张系列卡片。
3. 检查封面、分类、流程、对比、证据、清单和结尾的内容是否各有作用。
4. 逐张下载PNG，或使用批量下载；浏览器可能需要允许多文件下载。
5. 在历史记录中选择已保存内容，重新查看或渲染。

海报是模板排版卡片，不是自动生成产品摄影，也不会自动发布。
没有数据来源的图表数字不能直接发布。下载异常可能与浏览器或外部渲染脚本加载失败有关。

## 12. 热点洞察和飞书同步

“立即同步飞书数据”将配置好的飞书多维表格记录读取到系统；不是把所有文案自动写回飞书。
新版本输入关键词会进入采集中心，直接调用管理员配置的数据服务；不再执行Coze工作流。
页面可查看笔记样本、互动信息，并生成热点分析报告。

管理员需要配置飞书应用及表格访问权限、相应工作流或采集服务。没有配置时该入口不能完成采集或同步。
数据受来源、采集时点与同步状态影响，不应当作实时完整的小红书全平台榜单。
自动采集不是自动发布，也不代表已授权管理用户的小红书账号。

## 13. 发布和方法反馈

当前系统没有无人值守自动发布。工作台“前往小红书发布”打开小红书创作服务平台，由用户自行登录、上传图片并提交。

发布前检查：真实产品事实、品牌禁忌、标题与图片一致性、引用内容、广告表达及平台要求。
发布后在对应草稿中填写发布链接、点赞、评论、收藏、采用标记和反馈，点击“保存修改与反馈”。

“方法反馈”统计当前用户的产出、采用、发布及手工回填指标。
多方法同时用于一篇时，每个方法都会计入，不能据此判定哪一个方法单独带来了效果。
后续同品牌生成会参考已有文字反馈，因此建议写具体意见，例如“少用夸张开头，多用真实使用细节”。
互动数据不会自动从小红书拉取，需要定期人工更新。

## 14. 团队协作和管理员

品牌资料、方法库、爆文库及部分内容记录由已审核团队共享，不是按品牌划分的独立私密空间。
自己的工作台任务、草稿和方法统计按账号隔离。内容删除限本人或管理员；部分共享资料允许团队用户编辑或删除。
不要把不应团队共享的资料放入共享品牌和样本库。

管理员在“用户管理”审核注册申请、设置管理员或删除账号；管理权限只交给可信负责人。
工作台“运行状态”只对管理员显示，检查AI、数据库、飞书基础凭证及发布方式。
显示“已配置”只说明必要参数存在，不代表实际AI调用、发信或同步已验证成功。

## 15. 常见问题

| 情况 | 建议处理 |
| --- | --- |
| 忘记登录邮箱 | 联系管理员核对注册记录；系统用户名是邮箱 |
| 验证码没收到 | 核对注册邮箱、查垃圾邮件、等60秒后重发；仍失败联系管理员检查SMTP |
| 提示邮件服务未配置 | 管理员补齐SMTP参数并重启；不要把授权码发给其他用户 |
| 验证码失效 | 使用最新验证码，确认10分钟内且未连续输错5次 |
| 登录失效 | 重置密码后重新登录；不能恢复旧令牌 |
| 文案生成失败 | 工作台查看失败原因，只重试失败篇；检查AI代理配置与网络 |
| 文案仍很相似 | 扩充方法与样本，改变场景/观点，选择明显或探索，并人工复核 |
| 关闭页面后找不到结果 | 工作台查看任务；旧生成页面未保存的结果可能丢失 |
| 找不到保存的文案 | 到对应页面历史区，或工作台任务记录，检查品牌过滤 |
| 文件上传失败 | 检查格式及20MB限制；扫描PDF优先转为可复制文字 |
| 飞书同步或采集失败 | 联系管理员核对凭证、权限、工作流与来源服务 |
| 页面看起来仍是旧版 | 强制刷新，管理员核对/api/health提交号；GitHub提交不等于服务器已更新 |

遇到问题，提供页面地址、操作步骤、发生时间和不含敏感信息的错误截图。
无需提供密码、验证码、SMTP授权码或AI Key。

## 16. 一次完整工作示例

主题：办公室咖啡杯选购。以下是流程示例，不是某品牌事实。

1. 品牌管理中录入已确认的杯体材质、清洗方式、价格、人群和禁用表达。
2. 建立“购买前疑问”“日常场景”“使用技巧”三个方法。
3. 工作台选择品牌，目标选“种草转化”，篇数选3，差异化选“明显”。
4. 必须强调里写“只使用已确认资料，不虚构测试数据或购买体验”。
5. 查看3篇是否分别覆盖选择标准、办公室场景、清洗使用等不同角度。
6. 检查文字重合提示，修改事实和语气，保存各篇到内容库。
7. 为其中一篇制作海报，人工发布，回填链接与反馈。

普通用户不需要操作服务器。部署、数据备份和服务凭证由管理员维护，分别参考项目的升级说明、密码恢复配置说明和安全更新说明。

## 17. 新增采集中心（需部署新版本与接入数据源）

本地新增`collection.html`，提供“关键词搜索”和“指定达人账号”两个任务入口。
可选择目标笔记数、每篇评论上限，查看任务进度、作者、正文、链接与互动数据，并筛选和导出JSON。
达人入口接受主页链接，也可使用该达人笔记链接让数据源识别作者。
