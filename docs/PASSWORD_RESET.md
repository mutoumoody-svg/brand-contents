# 邮箱密码恢复

登录页“忘记密码”进入`/forgot-password.html`。填写注册邮箱，获取6位验证码，再填写两次新密码。
验证码10分钟有效，60秒发送间隔，每邮箱每小时最多5次；单码最多5次验证尝试，成功后不可重用。
重置会撤销该用户旧登录令牌，不改变账号审核状态、品牌或内容。
数据库仅保存带随机nonce的HMAC验证码摘要，不保存验证码或新密码原文。
未注册邮箱返回统一提示，不发送邮件。邮件发送失败只记错误类别，不打印验证码、邮箱密码或邮件内容；页面统一提示不能保证邮件已投递。

## 配置发件服务

在服务器`/var/www/brand-contents/brand.env`添加以下配置，填写真实值但不要发送给聊天或提交Git。
已有`.env`也可配置；同名变量以`brand.env`为准。

```env
SMTP_HOST=你的SMTP服务器
SMTP_PORT=465
SMTP_USER=发件邮箱
SMTP_PASS=SMTP授权码或邮件服务密码
SMTP_FROM=发件邮箱
```

465使用直接TLS；587使用强制STARTTLS。不会关闭证书校验。使用邮箱服务商给出的SMTP地址和授权凭据，不默认使用网页登录密码。
`SMTP_FROM`须为邮件服务允许的发件地址。企业邮箱还需按服务商要求完成域名验证。
配置完成后运行`pm2 restart brand-contents --update-env`，在恢复页面实际发送并检查邮件（含垃圾邮件）。
服务器需允许出站SMTP连接；公开状态接口只说明变量齐全，不代表发送通路验证成功。

发送服务未配置时页面会显示“邮件服务尚未配置”，不会假装发出验证码。
请求频率限制存储SQLite，服务重启不清空。IP限额使用真实连接来源；Nginx反代下同一服务器入口共享60次/小时限额，不信任任意客户端X-Forwarded-For。

资料：https://nodemailer.com/smtp
